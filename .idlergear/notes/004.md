Slot-based retrieval implementation complete

**What was built**:
1. `klareco/rag/slot_indexer.py` - SlotBasedIndexer class
   - Extracts SUBJ/VERB/OBJ slots from AST
   - Stores separate embeddings for each role
   - Preserves grammatical features (negation, tense, mood)

2. `klareco/rag/slot_retriever.py` - SlotBasedRetriever class
   - Two-stage retrieval: slot filtering → full embedding rerank
   - Handles partial queries (missing slots get 0.5 bonus)
   - Feature matching bonus (negation, tense alignment)
   - Explainable matches (shows which slots matched)

3. `scripts/index_slot_based.py` - Indexing script
   - Checkpoint/resume support
   - Limit option for testing
   - Progress logging

4. `scripts/demo_slot_retrieval.py` - Demo script
   - Tests critical queries: "Kiu kreis Esperanton?"
   - Interactive mode
   - Slot match explanations

**Key features**:
- No new training needed (uses existing 733K params)
- Backward compatible (stores full embedding as fallback)
- Leverages Esperanto's explicit case marking
- Expected: 35% → 60-70% recall
