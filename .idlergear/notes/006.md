Benchmark freeze root cause identified

**Problem**: Baseline SlotBasedRetriever loads entire 19GB index into RAM

**Evidence**:
- Line 59-68 in `slot_retriever.py`: Loads all 4.2M docs into `self.documents` list
- With Python/numpy overhead: 20-30GB+ RAM needed
- Causes system freeze/OOM

**Why it freezes**:
1. Query creation: OK (just samples 50 docs, writes to file)
2. Baseline retriever init: Tries to load 4.2M docs → **FREEZE**

**Solutions to test**:
1. **Skip baseline** - use only memory-efficient implementations
2. **Mmap retriever** - memory-mapped file access (no full load)
3. **FAISS retriever** - builds index, more efficient
4. **MultiFAISS** - separate FAISS per slot
5. **SQLite** - database backend, minimal RAM

**Recommendation**: Skip baseline, run mmap/faiss/multifaiss/sqlite only
