Benchmark script enhanced with detailed progress reporting

**Major improvements**:

1. **Progress updates every 5 queries** with:
   - Running avg latency (last 5 queries)
   - Running avg recall
   - Current memory usage
   - **ETA (estimated time remaining)**

2. **Checkpoint/resume support**:
   - Saves every 10 queries
   - Auto-resume on restart
   - Skip completed solutions

3. **Detailed logging**:
   - Query creation progress (every 500K docs)
   - Indexer load time
   - Retriever init time
   - Per-solution detailed summaries
   - Total benchmark time

4. **Better final output**:
   - Full comparison table (mean/median/p95)
   - Automatic recommendations:
     - 🚀 FASTEST
     - 🎯 MOST ACCURATE
     - 💾 LOWEST MEMORY

**Example progress output**:
```
[5/50] Latency: 125.3ms | Recall: 0.850 | Memory: 2048MB | ETA: 5m 30s
[10/50] Latency: 118.7ms | Recall: 0.862 | Memory: 2051MB | ETA: 4m 45s
```
