M4 Milestone Created: AST-Aware Deep Learning

**Milestone 8: M4 AST-Aware Deep Learning** (due 2026-03-01)

Goal: Add minimal structure-aware deep learning (4-8M params) that leverages AST representations to beat M3's deterministic+slot approach.

**Core principle: "AST as Thoughts"**
- Neural networks operate on structured ASTs, not raw text
- Preserves grammatical understanding from parser
- Enables structure-aware encoding (TreeLSTM/GNN)
- Maintains explainability (attention shows which AST nodes match)

**Created issues:**

**M4.1: TreeLSTM Sentence Encoder** (P0)
- #197: Parent issue
- #198: Implement TreeLSTMEncoder model (2-5M params)
- #199: Train on contrastive similarity triplets

**M4.2: AST-Constrained Attention** (P0)
- #200: Implement cross-attention with role constraints (1-2M params)

**Architecture:**
```
M3 Cascade Output (150K filtered candidates)
    ↓
M4 TreeLSTM Encoder (structure-aware sentence embeddings)
    ↓
M4 AST-Constrained Attention (explainable node-level matching)
    ↓
Final ranking: 97%+ recall with full explainability
```

**Expected improvements:**
- Recall: 95% (M3) → 97% (M4)
- Explainability: Show which AST nodes matched (attention weights)
- Parameters: 733K (M3) → 4-8M (M4) — still 100-200x smaller than typical models!
- Latency: 2ms (M3) → 4-5ms (M4) — acceptable for +2% recall

**Key innovations:**
1. **TreeLSTM**: Bottom-up encoding respects syntax tree structure
2. **Contrastive training**: Learns that morphological variants are similar
3. **Role-constrained attention**: Only matches SUBJ↔SUBJ, VERB↔VERB, OBJ↔OBJ
4. **Explainable**: Attention weights show exactly which parts matched

**Validates thesis:**
If M4 succeeds, it proves: **Minimal structure-aware deep learning (4-8M params) beats large unstructured models by leveraging deterministic AST representations**.
