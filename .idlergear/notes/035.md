**HNSWlib Slot Retriever - Detailed Design Document**

## Architecture Overview

Three-stage retrieval pipeline matching HybridFAISSMmapRetriever pattern:

**Stage 0: HNSW Pre-filtering** (~1-2ms)
- 4.2M docs → 500 candidates using HNSWlib graph traversal
- Memory-mapped HNSW index (disk-backed)
- Thread tuning for optimal CPU usage

**Stage 1: Mmap Slot Reranking** (~1ms)
- 500 docs → 100 candidates using slot-based scoring
- Reuses existing mmap slot embeddings
- Pre-computed norms for 20% speedup

**Stage 2: Final Ranking** (~0.5ms)
- 100 → top-k results
- Combined score: `slot_weight × slot_score + hnsw_weight × hnsw_score`

**Total Expected Latency**: 2-3.5ms (1.5-2x faster than FAISS 5.1ms)

## HNSWlib Parameters

Based on 2025 best practices for 4.2M vectors:

### **Construction Parameters** (build-time)
```python
M = 16                    # Connections per node (good balance)
ef_construction = 200     # Build quality (default, works well)
max_elements = 4_200_000  # Corpus size
```

**Rationale**:
- M=16: Standard default, good recall/memory balance
- ef_construction=200: Recommended starting point
- Can tune later: M=24, ef_construction=400 for higher recall

### **Search Parameters** (query-time)
```python
ef_search = 500  # Must be >= k (we want k=500 candidates)
k = 500          # Number of candidates for Stage 1
```

**Rationale**:
- ef_search=500: Matches our candidate count
- Higher ef_search = better recall but slower
- Can adjust dynamically: ef_search=1000 for higher accuracy

### **Space Metric**
```python
space = 'cosine'  # Our use case (normalized embeddings)
```

## Memory Optimizations

**P0: Lazy Metadata Loading**
- Build offset index (70 MB) instead of loading all docs (36.6 GB)
- Load metadata on-demand in Stage 1

**P1: Memory-Mapped HNSW Index**
```python
# HNSWlib supports index persistence
index.save_index(str(hnsw_file))
index.load_index(str(hnsw_file))  # Disk-backed, not full RAM load
```

**P1: Pre-computed Norms**
- Reuse existing mmap norm arrays from slot indexing
- Avoids recomputing norms during search

**P3: Thread Tuning**
```python
# HNSWlib uses OpenMP like FAISS
physical_cores = psutil.cpu_count(logical=False) or 8
os.environ['OMP_NUM_THREADS'] = str(physical_cores)
```

**Expected Memory Usage**:
- HNSW index: ~1.5-2 GB (30-40% less than FAISS IVF)
- Mmap slot embeddings: disk-backed (not in RAM)
- Offset index: ~70 MB
- **Total RAM**: ~2-2.5 GB (vs FAISS 3-4 GB)

## Critical Implementation Differences from FAISS

### **1. Index Creation**
```python
# FAISS (complex)
import faiss
quantizer = faiss.IndexFlatIP(dim)
index = faiss.IndexIVFPQ(quantizer, dim, nlist, m, nbits)
index.train(training_vectors)
index.add(vectors)

# HNSWlib (simple!)
import hnswlib
index = hnswlib.Index(space='cosine', dim=dim)
index.init_index(max_elements=num_docs, ef_construction=200, M=16)
index.add_items(vectors, ids)  # No training needed!
```

### **2. Search API**
```python
# FAISS
index.nprobe = 32
distances, indices = index.search(query, k)

# HNSWlib
index.set_ef(ef_search)  # Dynamic per query!
labels, distances = index.knn_query(query, k=k)
```

### **3. Persistence**
```python
# FAISS
faiss.write_index(index, str(index_file))
index = faiss.read_index(str(index_file), faiss.IO_FLAG_MMAP)

# HNSWlib (simpler)
index.save_index(str(index_file))
index.load_index(str(index_file))  # Automatically disk-backed
```

### **4. Distance Metric**
- FAISS: Returns **similarity scores** (higher = better) for inner product
- HNSWlib: Returns **distances** (lower = better) for cosine
- **Must invert**: `similarity = 1 - distance` for cosine space

### **Index Building**
```python
def _create_hnsw_index(self, hnsw_dir: Path):
    """Build HNSW index from full embeddings."""
    # Create index
    index = hnswlib.Index(space='cosine', dim=self.embedding_dim)
    index.init_index(
        max_elements=self.num_docs,
        ef_construction=self.hnsw_ef_construction,
        M=self.hnsw_M,
    )
    index.set_num_threads(physical_cores)
    
    # Load embeddings from JSONL
    full_embeddings = []
    ids = []
    with open(self.index_file) as f:
        for i, line in enumerate(f):
            doc = json.loads(line)
            full_embeddings.append(doc['full_embedding'])
            ids.append(i)
            
            if (i + 1) % 100000 == 0:
                logger.info(f"Loaded {i+1:,} embeddings...")
    
    # Add to index
    embeddings_array = np.array(full_embeddings, dtype=np.float32)
    index.add_items(embeddings_array, ids)
    
    # Save to disk
    hnsw_file = hnsw_dir / "full_embeddings.hnsw"
    index.save_index(str(hnsw_file))
    logger.info(f"HNSW index saved: {hnsw_file}")
```
