## Bug #2 Fix Strategy: Partial Match Bonus

**Problem**: Partial match bonus is 0.5 for all missing query slots, but for questions this is too low.

**Example**:
- Query: {SUBJ: kiu, VERB: fond, OBJ: esp}  # "Kiu fondis Esperanton?"
- Target: {SUBJ: None, VERB: fond, OBJ: esp}  # Old index, no subject extracted
- Current score: (0.3×? + 0.4×1.0 + 0.3×1.0) / 3 = varies
- With old index where target SUBJ=None: mismatch, no score for subject slot

**Actual scoring with current index**:
When both have slot: sim (0-1)
When query None, target has: 0.5
When query has, target None: 0 (no credit)

**Solution**: Make partial bonus question-aware
- For questions (ends with "?"): 0.8 partial bonus
- For statements: 0.5 partial bonus (unchanged)

**Implementation**: Pass `is_question` flag to slot_similarity() method
