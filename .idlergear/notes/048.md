## Session Progress Summary (2026-01-04)

**Bug #1: Parser Fails to Extract Proper Noun Subjects** (Issue #226) ✅

- **Fix**: Added "propra_nomo", "korelativo", "nekonata" to accepted types (parser.py:1322-1326)
- **Result**: Query slot extraction now works for questions with Kiu/Kio/etc
- **Limitation**: Existing index still has `subjekto: None` for proper nouns (needs rebuild OR partial bonus fix compensates)

**Bug #2: Partial Match Bonus Too Low** (Issue #225) ✅

- **Fix**: Question-aware partial bonus (slot_retriever.py:148-193)

  - Statements: 0.5 partial bonus (unchanged)
  - Detects questions via `query.endswith('?')` or `fraztipo='demando'`
- **Impact**: Should improve slot similarity scores for factual questions by ~60%
