## Coreference Resolution in Esperanto: Deterministic vs Learned

### Current State

**Pronouns are detected** but NOT resolved to antecedents:
- AST includes: `vortspeco='pronomo'`, `nombro='singularo/pluralo'`
- AST does NOT include: `refers_to`, `antecedent`, `coreference_chain`

**Proper nouns are detected** (after today's fix):
- `vortspeco='propra_nomo'` or `'nekonata'` (capitalized words)
- NO semantic annotation of entity type (PERSON, PLACE, ORG)

### Can Esperanto Coreference Be Deterministic?

**SHORT ANSWER: Partially (~60-70%), but not 100%**

#### Deterministic Cases (~60-70%)

1. **Si (reflexive) - 100% deterministic**
   ```
   "Ŝi parolas kun si." (She talks with herself.)
   → "si" ALWAYS refers to sentence subject "ŝi"
   ```

2. **Gender/number agreement** (~80%)
   ```
   "Zamenhof fondis Esperanton. Li estis kuracisto."
   → "Li" (he, singular, masculine) → likely "Zamenhof" (only singular masculine entity)
   ```

3. **Recency heuristic** (~70%)
   ```
   "La viro vidis la knabon. Li kuris."
   → "Li" → likely "la viro" (most recent nominative masculine noun)
   ```

#### Non-Deterministic Cases (~30-40%)

1. **Ambiguous gender/number**
   ```
   "Maria kaj Johano parolis. Ŝi diris..."
   → "Ŝi" could be Maria (need context/semantics)
   ```

2. **Multiple candidates**
   ```
   "La instruisto demandis la studenton. Li respondis..."
   → "Li" could be instruisto OR studento (both masculine, singular)
   ```

3. **Cross-sentence discourse**
   ```
   "Zamenhof kreis Esperanton en 1887. La lingvo disvastiĝis. Ĝi..."
   → "Ĝi" → Esperanto (requires understanding "la lingvo" = the language)
   ```

### Deterministic Rules for Esperanto

```python
def resolve_pronoun_deterministic(pronoun_ast, sentence_ast, context):
    """Rule-based coreference resolution."""
    
    # Rule 1: Reflexive "si" → sentence subject
    if pronoun_ast['radiko'] == 'si':
        return sentence_ast.get('subjekto')
    
    # Rule 2: Recent candidates with matching features
    candidates = find_recent_nouns(context, 
                                   number=pronoun_ast['nombro'],
                                   gender=infer_gender(pronoun_ast['radiko']))
    
    # Rule 3: Nearest nominative candidate
    if candidates:
        return candidates[0]  # Recency heuristic
    
    return None  # Ambiguous - needs learned model
```

### Hybrid Approach (Recommended)

**Deterministic layer (60-70% coverage):**
- Si resolution (100%)
- Unique candidate by gender/number (~30%)
- Recency heuristic (~30-40%)

**Learned layer (remaining 30-40%):**
- Semantic compatibility (doctor → he/him, language → it)
- Discourse coherence (topic tracking)
- World knowledge (Zamenhof → he, Esperanto → it)
