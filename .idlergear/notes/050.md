### Positive Impact

Parser changes STRENGTHEN the deterministic approach:

**Bug #1 fix (proper noun extraction)**:
- More information extracted deterministically from AST
- Proper nouns now usable for slot matching (was broken before)
- No learned parameters needed

**Bug #2 fix (question-aware partial bonus)**:
- Deterministic question detection (ends with '?' or fraztipo='demando')
- Rule-based bonus adjustment (0.8 vs 0.5)
- No learning required

### Impact on Retrieval Quality

**Before fixes** (8% factual accuracy):
```python

  → query_slots: {SUBJ: None, VERB: fond, OBJ: esperant}  # Bug #1
  → doc_slots: {SUBJ: None, VERB: fond, OBJ: esperant}
  → slot_similarity: (0.3*0.5 + 0.4*1.0 + 0.3*1.0) / 3 = 0.57  # Bug #2
```

**After fixes** (expected 50%+ factual accuracy):
```python
Query: "Kiu fondis Esperanton?"
  → query_slots: {SUBJ: kiu, VERB: fond, OBJ: esperant}  # ✓ Bug #1 fixed
  → doc_slots: {SUBJ: zamenhof, VERB: fond, OBJ: esperant}  # ✓ After rebuild
  → slot_similarity: (0.3*0.9 + 0.4*1.0 + 0.3*1.0) / 3 = 0.76  # ✓ Bug #2 fixed
```
