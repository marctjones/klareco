# Incremental Measurement Roadmap: Bug Fixes → Minimal AST → Full AST
## Date: 2026-01-04

## Philosophy

**AST addition is PLANNED**, not optional. The phased approach allows us to:
1. **Attribute improvements clearly** - know what each change contributed
2. **Validate assumptions** - confirm expected gains before next phase
3. **Make data-driven decisions** - measure, don't guess

## Three-Phase Roadmap

### Phase 1: Bug Fixes (IN PROGRESS)

**What**: Fix parser and retriever bugs without adding AST

**Changes**:
- ✅ Bug #1: Parser proper noun extraction (#226) - DONE
- ✅ Bug #2: Question-aware partial bonus (#225, slot_retriever.py) - DONE
- ⏳ Bug #2: Apply to 6 other retrievers (#230) - TODO
- ⏳ Rebuild corpus/index with fixed parser (#231) - TODO

**Measurement**:
```
Baseline (broken):    8% factual accuracy, 38% overall
After Bug #1+#2:      ??% factual accuracy, ??% overall
Expected improvement: +42pp factual (+17pp overall)
```

**Timeline**: 1-2 days (apply Bug #2, rebuild overnight)

**Success criteria**: Factual accuracy 50-55%, overall 55%+

### Phase 2: Minimal AST (PLANNED - #233)

**What**: Add word-level morphology + prep phrases to index

**Changes**:
- Add `minimal_ast` field to index (subjekto_words, verbo_words, objekto_words, prep_phrases, modifiers)
- Extend retrievers with AST-based reranking
- Index size: 20 GB → 28 GB (+40%)

**Measurement**:
```
After Phase 1:        50-55% factual accuracy
After Minimal AST:    ??% factual accuracy
Expected improvement: +10-15pp
Target:              65-70% overall accuracy
```

**Timeline**: 2-3 days (implementation + reindexing)

**What this phase enables**:
- Modifier matching ("grandan internacian" ≈ "novan universalan")
- Prepositional phrase matching ("en la domo" vs "ĉe la montaro")
- Entity type boosting ("Kiu X?" → boost proper noun subjects)
- Morphological pattern matching (prefixes/suffixes)

**Success criteria**: Overall accuracy 65-70%

### Phase 3: Full AST (PLANNED - #234)

**What**: Add separate enrichment index with full AST structure

**Changes**:
- Create enrichment_index.jsonl with complete ASTs
- Add lazy loading (O(1) lookup by text)
- Add `return_ast=True` parameter to retrievers
- Index size: 20 GB + 30 GB enrichment (+150% total)

**Measurement**:
```
After Phase 2:        65-70% accuracy
After Full AST:       Multi-hop reasoning enabled
Focus:               Complex compositional queries, not just accuracy
```

**Timeline**: 3-4 days (when needed for advanced features)

**What this phase enables**:
- Multi-hop reasoning ("Kiu posedis la ringon antaŭ Frodo?")
- Compositional query decomposition
- Syntax-aware paraphrasing detection
- Deep AST-based explainability
- Coreference resolution with full context

**Success criteria**: Multi-hop queries work, explainability improved

## Measurement Points

### Checkpoint 1: After Phase 1 (Bug Fixes)
```bash
# Run Q&A benchmark
python scripts/benchmark_slot_retrievers.py \
  --index data/indexes/slot_full \
  --qa-file data/qa_benchmark.json \
  --output results_after_bug_fixes.json

# Compare to baseline
python scripts/compare_results.py \
  baseline_results.json \
  results_after_bug_fixes.json
```

**Expected**:
- Factual: 8% → 50-55% (+42-47pp)
- Overall: 38% → 55%+ (+17pp)

**Decision**: If actual < 45%, investigate before Phase 2

### Checkpoint 2: After Phase 2 (Minimal AST)
```bash
# Rebuild with minimal AST
./scripts/index_slot.sh --with-minimal-ast

# Run benchmark again
python scripts/benchmark_slot_retrievers.py \
  --index data/indexes/slot_full \
  --output results_after_minimal_ast.json

# Compare Phase 1 → Phase 2
python scripts/compare_results.py \
  results_after_bug_fixes.json \
  results_after_minimal_ast.json
```

**Expected**:
- Overall: 55% → 65-70% (+10-15pp)
- Modifier-heavy questions: Biggest gains

**Decision**: If actual < 60%, investigate AST matching logic

### Checkpoint 3: After Phase 3 (Full AST)
Focus on qualitative evaluation:
- Can system answer multi-hop questions?
- Does explainability show full reasoning chain?
- Do complex compositional queries work?
