**Discovery**: Query fails to return correct answer ("Zamenhof") despite having 4.2M documents indexed.

**Investigation Results**:

1. **Data Pipeline Gap** ❌ CRITICAL

   - Main articles found: "Esperanto" (386 sentences), "L. L. Zamenhof", "La Espero"
   - BUT: None of these are in `data/corpus/unified_corpus.jsonl`
   - **Root cause**: Corpus rebuild (issue #231) hasn't been run yet

2. **API Mismatch** 🐛

   - Demo script passes it anyway → TypeError
   - Other retrievers accept this parameter

   - Blocks `diagnose_query_matching.py` script
   - Imported in `__init__.py` but file missing
