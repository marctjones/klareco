## Investigation Results: Low Q&A Accuracy (Task #39)

### Key Finding
**Answers ARE in corpus, but retrieval is failing**

### Evidence

1. **Question q001**: "Kiu fondis Esperanton?" (Who founded Esperanto?)
   - Expected answer: "Zamenhof"
   - Corpus contains: "ZAMENHOF, Aŭtoro de la lingvo Esperanto"
   - What retriever returned: "Ĝi estis fondita la 28-an de majo 2012 per simpla kunveno" (completely irrelevant)

2. **MemoryMapped retriever**: ALL queries returned empty results due to shape mismatch bug (now fixed)

3. **Other retrievers** (MultiFAISS, HNSW, ScaNN, Hybrid):
   - All showing 10-12% accuracy
   - Retrieved documents are completely irrelevant to queries
   - Example: Q about Esperanto's founding returns docs about tropical rainforests, Italian novels, etc.

### Root Cause Analysis

The compositional embeddings are **not capturing semantic meaning well enough**:

1. **Proper noun handling**: "Zamenhof" is being parsed as unknown/nekonata
   - Not getting proper semantic embedding
   - Lost in slot-based matching

2. **Slot matching too strict**: Questions may not align with document slot structure
   - Q: "Kiu fondis Esperanton?" (SUBJ=who, VERB=found, OBJ=Esperanto)
   - Doc: "ZAMENHOF, Aŭtoro de la lingvo Esperanto" (fragment, no verb)
   - Slot mismatch causes retrieval failure

3. **Embedding collapse**: Compositional embeddings may be too similar across different semantic domains
   - Need to check embedding space distribution
   - May need semantic similarity training (Stage 1)

### Recommended Fixes (Priority Order)

**P0 - Critical**:
1. Re-run benchmark with fixed MemoryMapped retriever
2. Check if any retriever improves with fix

**P1 - High**:
1. Implement proper noun boosting in retrieval
2. Add fallback to full-text search for <30% slot coverage
3. Train semantic similarity model (Stage 1) and integrate

**P2 - Medium**:
1. Analyze embedding space with t-SNE/UMAP
2. Add BM25 hybrid retrieval for factual queries
3. Implement query expansion for short queries

**P3 - Low**:
1. Fine-tune slot weights per question type
2. Add Wikipedia article title boosting
