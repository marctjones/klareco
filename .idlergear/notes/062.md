## ReVo (Reta Vortaro) Resource for Task #51

**Best resource found**: Reta Vortaro (ReVo) - GPL-licensed Esperanto dictionary

**Download sources**:
1. GitHub: https://github.com/open-esperanto/revo-archive
2. SourceForge: https://sourceforge.net/projects/retavortaro/
3. Direct XML: http://www.xdobry.de/esperantoedit/vortaro.xml.zip

**Format**: XML-based lexical items with multilingual definitions

**Key features for Task #51**:
- Contains synonym relationships (refgrp[@tip='sin'])
- Contains antonym relationships (refgrp[@tip='ant'])
- Contains hypernym/hyponym relationships (refgrp[@tip='super'], refgrp[@tip='sub'])
- Contains related terms (refgrp[@tip='vid'])
- Root word forms with various derivatives

**XML Structure Example**:
```xml
<art mrk="...">
  <kap><rad>fondo</rad>/o</kap>
  <drv mrk="fondo.0o">
    <snc>
      <dif>...</dif>
      <refgrp tip="sin">
        <ref cel="krei.0i">krei</ref>
        <ref cel="establ.0i">establi</ref>
      </refgrp>
    </snc>
  </drv>
</art>
```

**Implementation plan**:
1. Download revo.xml from GitHub
2. Parse XML to extract synonym/related term mappings
3. Build bidirectional synonym dictionary: {root: [synonyms]}
4. Build verb→agent noun mappings manually (100-200 most common)
5. Use for Task #50 pattern matching expansion
