## Embedding Improvement Strategy - Complete Task Map

This note documents the complete strategy for improving Klareco's compositional embeddings using the ReVo thesaurus, developed on 2026-01-05.

### Strategic Decision (from Note #61)
Prioritize AST-aware retrieval (Tasks #49-53) over embedding investigation (Tasks #40-48).

**Decision point**: After implementing AST retrieval, if accuracy >60%, skip deep embedding investigation. If <60%, then investigate embeddings.

### Current Status
- ReVo thesaurus downloaded: `data/raw/eo/dictionaries/revo/revo_semantic_relations.json`
- Contains: 1,943 synonyms, 173 antonyms, 3,351 hypernyms, 1,098 hyponyms

### Embedding Improvement Tasks (Created 2026-01-05)

#### ROOT Embedding Tasks

**Task #54**: Evaluate root embedding quality using ReVo synonym pairs
- Test if synonym pairs have high similarity (target: >0.7)
- Baseline comparison vs random words (target gap: >0.2)
- Antonym discrimination test
- Output: JSON report with mean similarities and failure cases
- Effort: 4-6 hours
- Priority: HIGH

**Task #56**: Prepare ReVo semantic relations for compositional embedding training
- Parse ReVo words into roots/affixes using parser
- Filter out morphological variants (same root ≠ synonym)
- Extract root-level synonym pairs (500-1000 expected)
- Generate compositional pairs (if "kre" ≈ "establ", then "krei" ≈ "establi")
- Validate against corpus vocabulary
- Output: `revo_root_synonyms.json`, `revo_compositional_pairs.json`
- Effort: 6-8 hours
- Priority: HIGH
- Blocks: Task #55, #54

**Task #57**: Design contrastive learning to respect compositional embeddings
- Strategy 1 (RECOMMENDED): Root-level contrastive learning only
- Train only root embeddings, freeze affixes
- Preserve morphological compositionality
- Validation: Test compositional transfer (if roots similar, all derived forms similar)
- Effort: 4-6 hours
- Priority: HIGH
- Blocks: Task #55

**Task #55**: Improve embeddings using ReVo semantic relations (contrastive learning)
- Use triplet loss: sim(word, synonym) > sim(word, random) + margin
- Option 2 (RECOMMENDED): Adjustment layer, keep base frozen
- Training data: 1,943 synonym pairs, 173 antonym pairs
- Expected improvement: synonym similarity 0.55 → 0.75
- Effort: 8-12 hours
- Priority: HIGH
- Dependencies: Task #54 (baseline), Task #56 (data), Task #57 (design)

- Expected: 5,000-10,000 mal- pairs, 1,000-3,000 -ej pairs
- Output: `affix_pairs.json`, `affix_triplets.json`, `affix_contexts.json`
- Effort: 8-10 hours

**Task #61**: Prepare ReVo semantic relations for affix training validation

**Task #60**: Train affix embeddings using transformation-aware contrastive learning
- Different loss functions per affix type:

- Expected improvement: mal- sim 0.65 → <0.3, -ej cluster 0.45 → >0.7
- Effort: 10-14 hours
- Priority: HIGH
- Dependencies: Task #59 (data), Task #61 (validation), Task #58 (evaluation)

### Expected Outcomes

**Root Embeddings**:
- Mean synonym similarity: current ~0.55 → target >0.75
- Synonym vs random gap: current ~0.10 → target >0.25
- Compositional transfer: All derived forms similar

**Affix Embeddings**:
- mal- polarity reversal: current ~0.65 → target <0.3
- -ej place clustering: current ~0.45 → target >0.7
- Transformation consistency: std current ~0.35 → target <0.15

### Key Architectural Principles

1. **Root-level training**: Train roots, not full words (preserves compositionality)
2. **Frozen affixes during root training**: Affix meanings are deterministic
3. **Frozen roots during affix training**: Only learn transformations
4. **Compositional validation**: Improvements must transfer to derived forms
5. **Three-tier data quality**: P0 (corpus+ReVo), P1 (corpus), P2 (ReVo only)

### Related to Strategic Goals

This aligns with Klareco's vision (VISION.md):
- Maximize deterministic processing (affixes stay fixed)
- Minimize learned parameters (only roots + affix vectors)
- Focus learned capacity on semantic meaning, not grammar

If AST-aware retrieval (Tasks #49-53) achieves >60% accuracy, these embedding improvements become lower priority (nice-to-have rather than critical).
