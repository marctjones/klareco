### Architecture

```
Query → Parser → AST
                  ↓
      ┌───────────┴───────────┐
      ↓                       ↓
QuestionClassifier      EntityRecognizer
      ↓                       ↓
 (question type)         (entities)
      ↓                       ↓
      └───────────┬───────────┘
                  ↓
         ASTAwareRetriever
                  ↓
         ┌────────┴────────┐
         ↓                 ↓
  PatternMatcher    SemanticDB
         ↓                 ↓
  (structural match) (synonyms)
         ↓                 ↓
         └────────┬────────┘
                  ↓
            Ranked Results
```

### Key Technical Achievements

1. **Fully Deterministic**: Zero learned parameters, 100% rule-based
2. **AST-Native**: Operates on parsed structure, not text similarity
3. **Synonym-Aware**: Integrates ReVo thesaurus for semantic matching
4. **Transformation-Aware**: Handles passive voice, appositive constructions
5. **Multi-Strategy**: Automatically selects strategy based on question type
6. **Explainable**: Can explain every retrieval decision

### Strategy Selection Logic

```python
WHO + entities     → entity-focused
WHERE questions    → entity-focused  
WHEN questions     → entity-focused
WHAT/HOW questions → pattern matching
2+ entities        → hybrid
```
