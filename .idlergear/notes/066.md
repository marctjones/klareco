### Technical Approach

**Pattern Matching**:
- Extracts SUBJ/VERB/OBJ from question and documents
- Matches with synonym expansion (ReVo thesaurus)
- Handles passive voice transformations
- Filters function words

**Strategy Selection** (automatic):
- WHO/WHERE/WHEN → entity-focused
- WHAT/HOW → pattern matching
- Multiple entities → hybrid

**On-the-Fly Parsing**:
```python
# Parse documents that don't have AST stored
doc_ast = doc.get('ast')
if not doc_ast:
    doc_ast = parse(doc['text'])
```

### Performance Notes

**Current Limitations**:
- Only scans first 10k documents (out of 4.3M total)
- On-the-fly parsing is slow (~30-60s per query)
- No pre-filtering with HNSW/FAISS

**Potential Optimizations** (if needed):
1. Pre-filter with HNSW (4.3M → 500 candidates)
2. Then AST-match top candidates
3. Expected: <5s per query with pre-filtering

**Alternative**: Build index with pre-parsed ASTs
- Faster: No on-the-fly parsing
- Larger: ASTs add ~2-3KB per document
- Tradeoff: 4.3M docs × 2KB = ~8.6GB additional storage
