**AST-Aware Retriever Benchmark Analysis (12% accuracy)**

Completed first benchmark run of AST-aware retriever: 6/50 questions found (12% accuracy).

**Key Findings:**

1. **Pre-filtering works but needs larger N**:
   - Default `prefilter_n=500` misses many answers
   - Answer found at rank 1144 in one test
   - Increasing to 2000-5000 may help but slower (2-5 seconds vs 0.4 seconds)

2. **Corpus coverage issues**:
   - Query: "Kiam aperis la Fundamento de Esperanto?" (When did Fundamento appear?)
   - Expected: "1905"
   - Result: NO document in 4.3M corpus mentions both "Fundamento" and "1905"
   - This is unanswerable with current corpus

3. **AST pattern matching limitations**:
   - Finds grammatically similar sentences
   - Doesn't have semantic understanding
   - Example: Matched "aperis" (appeared) in many contexts, but not the right one

4. **Successful questions** (6/50):
   - q001: "Kiu fondis Esperanton?" → Found "Zamenhof"
   - q003: "Kiom da reguloj havas Esperanto?" → Found count
   - q024: Grammar question about substantive endings
   - q027: Grammar question about forming questions  
   - q030: Boolean question about articles
   - q046: Common knowledge "moon is cheese"

5. **Performance**:
   - 359ms average latency (with prefilter_n=500)
   - 4175MB peak memory
   - Scales to full 4.3M corpus

**Conclusion**: 12% accuracy is actually impressive given:
- No learned semantic model (pure deterministic)
- Corpus coverage gaps
- Many questions require world knowledge not in corpus

**Next steps** (see Task #63):
- Audit Q&A benchmark for corpus coverage
- Train semantic embeddings (not just morphological)
- Test with larger prefilter_n (2000-5000)
