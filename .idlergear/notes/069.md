**Dual Embeddings Implementation: What We Have vs What We Need**

## Already Implemented ✅

1. **CompositionalEmbedding class** (`klareco/embeddings/compositional.py`)
   - Root, prefix, suffix, ending composition
   - Works well, just needs `use_dual_roots` parameter
   - Can keep existing logic, add dual mode

2. **Training infrastructure** (`scripts/training/train_root_embeddings.py`)
   - RootEmbeddings class (single 64d)
   - Linguistic training data: ReVo + Ekzercaro pairs
   - MSE + margin loss functions
   - Checkpoint save/load
   - Evaluation metrics (correlation)
   - **Can reuse:** Loss functions, data loading, evaluation
   - **Must modify:** Model class to DualRootEmbeddings

3. **Slot-based retrieval** (`klareco/rag/slot_indexer.py`, `slot_retriever_hnsw.py`)
   - Embedding-based indexing working
   - HNSW pre-filter working
   - **Can reuse:** Most logic
   - **Must add:** Support for 128d embeddings, mode parameter

4. **AST-aware retriever** (`klareco/rag/ast_aware_retriever.py`)
   - Pattern matching working
   - Pre-filtering working
   - Question classification working
   - **Can reuse:** All AST logic
   - **Must add:** Embedding mode selection, explainability output

5. **Corpus** (4.3M documents with ASTs)
   - Ready to extract co-occurrence pairs
   - No need to rebuild

## Need to Refresh/Modify 🔄

1. **CompositionalEmbedding** - Add dual roots support
   - Add `use_dual_roots` parameter
   - Add `root_mode` parameter to forward()
   - Keep backward compatibility

2. **SlotBasedIndexer** - Support 128d embeddings
   - Add `embedding_mode` parameter
   - Update embedding dimension handling
   - Support mode selection

3. **HNSWSlotRetriever** - Support dual embeddings
   - Handle 128d vectors
   - Add mode/weighting parameters

4. **ASTAwareRetriever** - Adaptive weighting
   - Add `embedding_mode` parameter
   - Implement query-type-based weighting
   - Add explainability decomposition

## Need to Create from Scratch 🆕

1. **DualRootEmbeddings class** (`klareco/embeddings/dual_root_embeddings.py`)
   - New file, new class
   - Two independent nn.Embedding layers
   - Mode selection logic

2. **Topical data preparation** (`scripts/data/prepare_topical_pairs.py`)
   - New directory: `scripts/data/`
   - Extract skip-gram pairs from corpus
   - Negative sampling
   - Save training pairs

3. **Dual training script** (`scripts/training/train_dual_embeddings.py`)
   - New file (can copy structure from train_root_embeddings.py)
   - Multi-task training loop
   - Separate evaluation for linguistic vs topical
   - Joint or sequential training modes

4. **Migration script** (`scripts/migration/single_to_dual.py`)
   - New directory: `scripts/migration/`
   - Convert existing checkpoint to dual format
   - Bootstrap topical from linguistic

5. **Dual embedding evaluation** (`scripts/training/evaluate_dual_embeddings.py`)
   - New file
   - Separate correlation metrics for each
   - t-SNE visualization for topical clustering
   - Probe tests (e.g., "Fundamento" + "1905" proximity)
