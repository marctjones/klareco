### Key Design Decisions

1. **Sequential Training Recommended**: Train linguistic first, freeze, then train topical
   - Safer than joint training (avoids interference)
   - Can reuse existing linguistic embeddings
   - Faster convergence

2. **Skip-gram Window Size = 5**: Captures medium-range context
   - Distance 1: target=0.7 (very similar)
   - Distance 5: target=0.3 (weakly related)

3. **Negative Sampling 5:1**: Standard ratio for word2vec-style training

4. **Backward Compatibility**: All existing code works unchanged
   - Default `use_dual_roots=False` preserves single embedding behavior
   - Can load old checkpoints
