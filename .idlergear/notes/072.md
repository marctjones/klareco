## Dual Embeddings Training Script Implementation (Task #71)

Created `scripts/training/train_dual_embeddings.py` with sequential training strategy:

**Phase 1: Topical Training (Linguistic Frozen)**
- Load pre-trained linguistic embeddings from `models/root_embeddings/best_model.pt`
- Initialize DualRootEmbeddings with loaded linguistic weights
- Freeze linguistic parameters (`requires_grad = False`)
- Train only topical embeddings for 10 epochs
- Loss: MSE on cosine similarity for skip-gram pairs
- Optimizer: Adam (lr=0.001) on topical params only

**Phase 2: Joint Fine-tuning (Optional)**
- Unfreeze all parameters
- Train both embeddings jointly for 5 epochs
- Lower learning rate (0.0001) to avoid catastrophic forgetting
- Loss: Same MSE on cosine similarity but updates both embeddings

**Key Features:**
- Atomic checkpoint saves (write to .tmp then rename)
- Separate checkpoints for topical_best and joint_best
- File logging to `logs/training/dual_training_*.log`
- Progress logging every 100K pairs
- Batch processing (default 1024)
- Device support (CPU/CUDA)

**Shell wrapper:** `scripts/train_dual_embeddings.sh`
- Validates all inputs exist
- Auto-activates venv
- Logs to timestamped file
- Shows estimated time (30-60 min)

**Training data:** `data/training/topical_pairs_smart.jsonl` (currently generating)
- Format: {idx1, idx2, target_similarity, weight, root1, root2}
- Expected size: ~8.7M pairs (2.9M positive + 5.8M negative)
