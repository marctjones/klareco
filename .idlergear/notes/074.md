## Refactored to Separate Linguistic and Topical Embeddings (Task #77)

**Completed full architecture refactor based on user insight that different words need different embedding types.**

### Problem Identified
DualRootEmbeddings forced same vocabulary for both embeddings, but:
- Proper nouns (Napoleono, Parizo) only have topical meaning
- Content words (hund, bel) have both linguistic + topical
- Function words (kaj, de) have neither (handled by AST)
- Rare/technical terms may only have topical

**Forcing same vocab wasted 64d storage and didn't match semantic reality.**

### New Architecture

**Three independent models:**

1. **LinguisticEmbeddings** (`klareco/embeddings/linguistic_embeddings.py`)
   - 64d per root
   - Curated content words (~11K-15K roots)
   - Trained on ReVo relations + semantic similarity pairs
   - Stable vocabulary (grows slowly)

2. **TopicalEmbeddings** (`klareco/embeddings/topical_embeddings.py`)
   - 64d per root
   - ALL corpus roots (~77K including proper nouns)
   - Trained on skip-gram pairs from corpus
   - Dynamic vocabulary (grows with corpus)

3. **HybridEmbeddings** (`klareco/embeddings/hybrid_embeddings.py`)
   - Smart combiner at inference time
   - Looks up each root in both vocabularies
   - Returns available embeddings (64d, 128d, or None)
   - Handles missing gracefully with configurable padding

### Key Features

**Vocabulary independence:**
- Linguistic: `root in linguistic_vocab` → has semantic meaning
- Topical: `root in topical_vocab` → appears in corpus
- Overlap: ~14% (most common content words in both)

**Smart combining:**
```python
# Content word: both available
"hund" → [ling_64d, top_64d] = 128d

# Proper noun: topical only
"Parizo" → [zeros_64d, top_64d] = 128d (with pad_missing=True)

# Unknown: neither available
"foobar" → None
```

**Root type classification:**
- `content_word`: Has both embeddings
- `proper_noun_or_rare`: Topical only
- `linguistic_only`: In linguistic vocab but not in corpus (rare)
- `unknown`: Not in either vocab

### Files Created

- `klareco/embeddings/linguistic_embeddings.py` - Linguistic model

### Files Deprecated

- `klareco/embeddings/dual_root_embeddings.py` - Old forced-same-vocab approach
- `scripts/training/train_dual_embeddings.py` - Old combined training
- `scripts/train_dual_embeddings.sh` - Old shell wrapper

### Benefits

1. **Storage efficiency** - Don't store useless embeddings for proper nouns
2. **Vocabulary independence** - Linguistic stable, topical grows
3. **Clear semantics** - Presence in vocab = has that type of meaning
4. **Better for new words** - Add proper nouns to topical only
5. **Flexible deployment** - Use linguistic-only, topical-only, or hybrid modes
