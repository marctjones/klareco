## Topical Data Generation Complete + 6900x Performance Optimization

**Problem:** Original negative generation was taking 98 hours (4 days) due to inefficient sampling.

**Root Cause:** 
- Recreated 77K-element weight list on EVERY iteration
- Called `random.choices()` with weight computation per sample
- Rate: 16 negatives/sec (970/min)

**Solution:** Batch sampling with pre-computed weights
- Pre-compute weight list ONCE
- Sample in batches of 10,000
- Rate: **111,000 negatives/sec**
- **Speed improvement: 6,900x faster**

**Results:**
- Generated 5.68M negatives in **51 seconds** (vs 98 hours)
- Total dataset: 8.66M pairs (2.89M positive + 5.77M negative)
- Ratio: 1:2.00 (perfect)
- File size: 951 MB
- Memory: ~400MB stable

**Code Changes:**
- Modified `generate_smart_negatives()` in `scripts/data/generate_topical_pairs_smart.py`
- Created `scripts/data/generate_negatives_only.py` for quick completion

**Key Optimization:**
```python
# BEFORE (slow):
r1 = random.choices(roots_list, weights=[root_weights.get(r, 0) for r in roots_list])[0]
# Recreates 77K list every call!

# AFTER (fast):
weights_list = [root_freq.get(r, 0) / total_freq for r in roots_list]  # Once
r1_batch = random.choices(roots_list, weights=weights_list, k=10000)  # Batch
```
