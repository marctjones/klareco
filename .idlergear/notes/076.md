## Session Summary: Complete Dual Embeddings Architecture Refactor

**Date:** 2026-01-05  
**Duration:** ~3 hours  
**Status:** ✅ COMPLETE - Ready for retrieval integration

### Major Accomplishments

#### 1. Architecture Refactor (Task #77) ✅
**Problem Identified:** DualRootEmbeddings forced same vocabulary for both embeddings, wasting storage and not matching semantic reality.

**Solution Implemented:**
- Separated into 3 independent models:
  - `LinguisticEmbeddings` - 11K curated content words, semantic similarity
  - `TopicalEmbeddings` - 77K all corpus roots, co-occurrence patterns
  - `HybridEmbeddings` - Smart combiner with vocab independence

**Benefits:**
- Storage efficient (no wasted embeddings for proper nouns)
- Vocabulary independence (linguistic stable, topical grows)
- Clear semantics (presence in vocab = has that type of meaning)
- Flexible inference (linguistic, topical, or hybrid modes)

#### 2. Data Generation Complete ✅
**Generated:** 8.66M training pairs (2.89M positive + 5.77M negative)
- Ratio: 1:2.00 (perfect)
- File size: 951 MB
- Coverage: 300 pairs per root (balanced)

**Performance Optimization:** 6,900x speedup
- Old: 16 negatives/sec (would take 98 hours)
- New: 111,000 negatives/sec (completed in 51 seconds)
- Key: Pre-computed weights + batch sampling

#### 3. Topical Embeddings Training Complete ✅
**Results:**
- 10 epochs completed (~60 minutes)
- Final loss: 0.0358 (started at 0.4195)
- Loss reduction: 91.5%
- Model: `models/topical_embeddings/best_model.pt`

#### 4. Testing & Validation ✅

- Proper noun handling: Mostly topical-only (correct)

**Test results:** All passing, ready for production

### Key Insights

**User insight that drove refactor:**
"Why do they have to have the same vocabulary? Won't some words only have topical semantics like proper nouns?"

**This was exactly right** and led to a much better architecture where:
- Proper nouns (Parizo, Napoleon) → topical only
- Content words (hund, bela) → both embeddings
- Function words (kaj, de) → neither (AST handles)
