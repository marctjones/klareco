SlotBasedIndexer hybrid embeddings integration complete (2026-01-06)

**Changes made:**
1. Added `topical_model_path` and `use_hybrid` parameters to `__init__`
2. Loads HybridEmbeddings when `use_hybrid=True`
3. Uses 128d embeddings (64d linguistic + 64d topical)
4. Fallback to linguistic-only for backward compatibility
5. Temporarily skips affix transforms for hybrid mode (Task #83 to fix)

**Key insight:**
Retrievers (FAISS, HNSW, etc.) don't need code changes - they auto-detect embedding dimension from the data. Only need to rebuild indexes with new 128d embeddings.
