## Hybrid Embeddings Integration Complete

Successfully integrated hybrid embeddings (128d) into the indexing and retrieval pipeline.

**Changes Made:**

1. **SlotBasedIndexer** (`klareco/rag/slot_indexer.py`):
   - Added `topical_model_path` and `use_hybrid` parameters
   - Loads HybridEmbeddings when `use_hybrid=True`
   - Uses 128d embeddings (64d linguistic + 64d topical)
   - Temporarily skips affix transforms in hybrid mode (need 128d versions - see Task #83)
   - Backward compatible: defaults to 64d linguistic-only mode

2. **Indexing Script** (`scripts/index_slot_based.py`):
   - Added `--topical-model` argument
   - Added `--hybrid` flag
   - Validates that `--topical-model` is provided when using `--hybrid`
   - Logs embedding mode in output

3. **Build Script** (`scripts/build_hybrid_indexes.sh`):
   - Created master script to rebuild all indexes with hybrid embeddings
   - Builds slot index, FAISS, HNSW, MemoryMapped, and ScaNN indexes
   - Includes prerequisite checks

**Testing:**
- Tested with 100 sentences from unified corpus
- ✓ Embeddings are correctly 128d
- ✓ 100% success rate
- ✓ HybridEmbeddings properly initialized (11K linguistic + 77K topical roots)

**Key Insight:**
Retrievers (FAISS, HNSW, etc.) automatically detect embedding dimension from data, so they don't need code changes - only need to rebuild indexes with new 128d embeddings.
