## Topical Vocabulary Coverage Investigation

**Date:** 2026-01-06
**Context:** While waiting for hybrid index build (Task #79), investigated potential vocabulary gaps in topical embeddings.

### Initial Concern
Validation tests showed 'matemat' and 'geometri' missing from topical vocabulary, raising concerns about academic term coverage.

### Investigation Method
Tested 49 representative roots across 4 categories:
- Math & Science (11 terms)
- Humanities (11 terms)
- Common Content (15 terms)
- Proper Nouns (12 terms)

### Key Finding
**96% coverage (47/49 terms found)**

The perceived gap was due to test methodology using incorrect root forms:
- ❌ Tests used: 'matemat' (not in vocab)
- ✅ Parser extracts: 'matematik' (in vocab)

### Coverage by Category
```
Math & Science:   11/11 (100%) - matematik, geometri, fizik, kemi, etc.
Humanities:       10/11 (91%)  - missing only 'politi'
Common Content:   15/15 (100%) - hund, kat, arb, flor, etc.
Proper Nouns:     12/12 (100%) - napoleon, pariz, london, etc.
```

### Vocabulary Statistics
- Linguistic: 953,549 roots
- Topical: 77,236 roots
- Overlap: 77,115 roots (99.8%)

### Implications
1. Task #84 should be closed or downgraded - no significant gap exists
2. Validation tests need correction - use correct root forms
3. Hybrid embeddings will work well with current vocabulary
4. Only genuine missing term from test set: 'politi'

### Lesson Learned
Always verify root extraction behavior before assuming vocabulary gaps. The parser may extract different root forms than expected (e.g., 'matematik' not 'matemat').
