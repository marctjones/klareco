# Retriever Architecture Review for Hybrid Embeddings

## Key Finding: SlotBasedIndexer is the Embedding Source

All retrievers that require an `indexer: SlotBasedIndexer` parameter use it for:
1. **Query embedding** - converting query text to 64d or 128d vectors
2. **Slot extraction** - parsing query AST and embedding SUBJ/VERB/OBJ

The SlotBasedIndexer determines whether 64d (linguistic-only) or 128d (hybrid) embeddings are used.

## Retriever Compatibility Matrix

| Retriever | Requires SlotBasedIndexer? | Hybrid Compatible? | Memory Safe? |
|-----------|---------------------------|-------------------|--------------|
| **ASTAwareRetriever** | No (loads own HybridEmbeddings) | ✅ Yes (auto-detects dim) | ✅ Yes |
| **HNSWSlotRetriever** | Yes | ✅ If indexer is hybrid | ✅ Yes (mmap) |
| **FAISSSlotRetriever** | Yes | ✅ If indexer is hybrid | ✅ Yes (mmap) |
| **HybridFAISSMmapRetriever** | Yes | ✅ If indexer is hybrid | ✅ Yes (mmap) |
| **MultiFAISSSlotRetriever** | Yes | ✅ If indexer is hybrid | ✅ Yes |
| **ScaNNSlotRetriever** | Yes | ✅ If indexer is hybrid | ✅ Yes |
| **SQLiteSlotRetriever** | Yes | ✅ If indexer is hybrid | ✅ Yes |
| **MemoryMappedSlotRetriever** | Yes | ✅ If indexer is hybrid | ✅ Yes (mmap) |

## ASTAwareRetriever is Special

ASTAwareRetriever (lines 174-185 of ast_aware_retriever.py) automatically:
1. Detects embedding dimension from slot_index.jsonl first doc
2. Loads HybridEmbeddings if both models exist
3. Falls back to LinguisticEmbeddings if only root model exists

This makes it the most "plug and play" retriever for hybrid embeddings.

## The Problem: Index Must Match Embedder

For retrievers that use pre-built indexes (HNSW, FAISS, mmap), the index dimension MUST match:
- `slot_hybrid/` has 128d embeddings in slot_index.jsonl
- `slot_hybrid/hnsw/` has 128d HNSW index
- BUT `slot_hybrid/` is missing: faiss/, mmap/ directories

If we build these from slot_index.jsonl, they'll be 128d and compatible.

## Recommendation

1. **ASTAwareRetriever** - Works NOW with slot_hybrid/ (auto-detects 128d)
2. **HNSWSlotRetriever** - Needs mmap/ arrays built (128d)
3. **FAISSSlotRetriever** - Needs faiss/ index built (128d)
4. **HybridFAISSMmapRetriever** - Needs both faiss/ and mmap/

All other retrievers (MultiFAISS, ScaNN, SQLite, MemoryMapped) should be deprecated for now since we don't have indexes for them and building them is lower priority.
