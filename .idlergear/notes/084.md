# Retriever Deprecation for Hybrid Embeddings (2026-01-06)

## Decision
Deprecated 4 retrievers that don't have hybrid embedding indexes built.
Keeping 4 active retrievers for the hybrid embeddings evaluation.

## Active Retrievers (128d hybrid embeddings)
1. **ASTAwareRetriever** - Full AST analysis, auto-detects embedding dim
2. **HNSWSlotRetriever** - HNSW prefilter + mmap slots (fastest)
3. **FAISSSlotRetriever** - FAISS prefilter + slot rerank
4. **HybridFAISSMmapRetriever** - FAISS + mmap hybrid (best accuracy)

## Deprecated Retrievers (still in slot_full/ with 64d)
1. MultiFAISSSlotRetriever - Per-slot FAISS indexes
2. ScaNNSlotRetriever - ScaNN prefilter (requires TensorFlow)
3. SQLiteSlotRetriever - SQLite storage
4. MemoryMappedSlotRetriever - Pure mmap

## Rationale
- Building indexes for all 8 retrievers would take hours
- Focus on the 4 most promising approaches for hybrid embeddings
- Deprecated retrievers still work with `slot_full/` (64d) if needed
- Can un-deprecate later if needed by building hybrid indexes

## Index Status for slot_hybrid/
- ✅ slot_index.jsonl (4.37M docs, 128d embeddings)
- ✅ hnsw/full_embeddings.hnsw (2.9GB)
- ❌ mmap/ (needs building - run build_hybrid_mmap_faiss.sh)
- ❌ faiss/ (needs building - run build_hybrid_mmap_faiss.sh)

## Shell Script
Run in separate terminal:
```bash
./scripts/build_hybrid_mmap_faiss.sh
```
- Restartable with checkpoints every 100K docs
- Memory-safe (disk-backed mmap arrays)
- Logs to logs/build_hybrid_indexes_*.log
