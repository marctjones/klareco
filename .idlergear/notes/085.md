## Retriever Analysis: Linguistic vs Topical Embeddings

### How Hybrid Embeddings Work

**Architecture** (from `hybrid_embeddings.py`):
- **Hybrid Mode (128d)**: Concatenates [linguistic_64d + topical_64d]
- **Linguistic (64d)**: Semantic/dictionary-based (hundo~kato, bela~ĉarma) - 11,121 roots
- **Topical (64d)**: Co-occurrence/contextual (Parizo~Francio, hundo~manĝi) - 77K roots

```python
# hybrid_embeddings.py get_root_embedding() 
if has_ling and has_top:
    embs = [ling_64d, top_64d]  # → 128d
elif has_ling:
    embs = [ling_64d, zeros_64d]  # → 128d (topical padded)
elif has_top:
    embs = [zeros_64d, top_64d]  # → 128d (linguistic padded)
else:
    return None  # No embedding
```

### Key Findings from Evaluation Results

**ASTAware Retriever** (30% R@10, best on factual):
- Uses HybridEmbeddings for HNSW prefilter
- Question "Kiu fondis Esperanton?" → roots: `['kiu', 'fond', 'esp']`
- Returns 500 candidates with ANY `fond*` + `esperant*` match
- Problem: Matches "li fondis firmaeton" not "Zamenhof fondis Esperanton"

**FAISS Retriever** (20% R@10, 100% on diagnostic):
- Pure embedding similarity (no slot reranking)
- Excels at exact/near-exact phrase matching
- Fails on factual questions requiring entity recognition

### Improvement Opportunities for ASTAware

1. **Increase prefilter_n**: 500 → 1000+ for factual questions
2. **Named entity boosting**: When "Kiu" (who), boost docs with proper nouns in subject
3. **Better root extraction**: Keep full "esperant" instead of truncating to "esp"
4. **Tier-aware boosting**: Authoritative sources should rank higher
