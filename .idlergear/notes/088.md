## AST-Aware Retrieval Improvements (2026-01-06)

### Implemented Changes

1. **OR-matching grep for semantic role expansion** (`ast_aware_retriever.py:580-678`)
   - When query has creator verb (fond/kre/invent), expand with OR pattern for all creator terms
   - Enables finding "aŭtoro de Esperanto" when searching for "fondis Esperanton"
   - Keywords split into AND-keywords (non-role) and OR-keywords (role expansion)

2. **Supplementary keyword search** (`ast_aware_retriever.py:1002-1015, 1098-1113`)
   - Added to both entity-focused and hybrid search strategies
   - Merges keyword candidates with HNSW candidates to find semantically equivalent docs
   - Adds ~249 candidates from keyword search

3. **Semantic role bonus in Stage 2** (`ast_aware_retriever.py:1163-1181`)
   - Detects if query has creator verb
   - If doc contains creator noun (aŭtor/kreint/etc), adds bonus:
     - 2.5 bonus if doc has no verb (title/heading like "X, Aŭtoro de Y")
     - 1.5 bonus if doc has verb
   - Score formula: 0.35*entity + 0.35*pattern + 0.3*semantic_bonus

### Results

For query "Kiu fondis Esperanton?":
- "ZAMENHOF, Aŭtoro de la lingvo Esperanto" now ranks #41 (score 0.890)
- Previously not in top 100
- Top results still about "fondis Esperanto-organizon" (score ~1.6)

### Remaining Challenges

1. **Object position disambiguation**: Query has "Esperanton" as direct object core, but matches documents with "Esperanto" in modifier position (e.g., "Esperanto-rondon")

2. **Pattern matcher scores**: Documents with verb "fondis" get high pattern scores even when object is different

3. **Entity score gap**: Documents with both entity AND pattern match score 1.6+, while semantic-role-equivalent docs score ~0.9

### Next Steps

- Consider boosting documents where query object appears as CORE not MODIFIER
- Position-aware matching already implemented in pattern_matcher (`_match_core_positions`)
- May need to integrate position scoring into Stage 2 combined score
