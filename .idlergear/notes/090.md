## ASTAwareRetriever Definition Question Fixes (2026-01-07)

### Problem
Definition questions ("Kio estas hundo?") were returning irrelevant results because:
1. HNSW query embedding averaged ALL roots equally, diluting the predicate nominative
2. Slot similarity was normalizing by matched_slots, penalizing documents with more matching slots

### Fixes Implemented

**1. Weighted Query Embedding** (`_embed_query_ast`, lines 406-498):
- For definition questions (verb="esti" + noun in aliaj):
  - Predicate nominative (X in "Kio estas X?"): 2.0x weight
  - Correlatives (kio, kiu): 0.1x weight  
  - Copula verb (estas): 0.2x weight
- This ensures HNSW finds documents about X, not random sentences with "estas"

**2. Raw Slot Score for Definitions** (`_compute_slot_similarity`, lines 392-404):
- Don't normalize by matched_slots for definition questions
- Having PRED_TO_SUBJ AND VERB match scores higher than just PRED_TO_SUBJ
- Rewards actual definitions "X estas Y" over mere mentions

**3. Disabled Supplementary Keyword Prefilter** (lines 1107-1124, 1228-1243):
- When HNSW is available, skip supplementary keyword search
- Eliminates 30s timeout on large corpus
- No accuracy impact (HNSW+slot reranking is sufficient)

### Results
- Top-5 accuracy: 66.7% → 75%
- No more "Keyword prefilter timed out" messages
- HNSW prefilter now returns 20/20 relevant documents for definition queries
