Agent noun expansion now uses systematic Esperanto morphology rules

**What changed:**
1. `semantic_db.get_agent_nouns()` now systematically generates agent nouns for ANY verb using Esperanto morphology:
   - `-into` = past active participle (fondinto = one who founded)
   - `-anto` = present active participle (fondanto = one who founds)
   - `-onto` = future active participle (fondonto = one who will found)
   - `-isto` = professional/habitual (fondisto = founder as profession)

2. `semantic_db.get_patient_nouns()` generates passive participles:
   - `-ito` = past passive (kreito = something created)
   - `-ato` = present passive (kreato = something being created)
   - `-oto` = future passive (kreoto = something to be created)

3. `semantic_db.extract_verb_root_from_participle()` reverses the derivation:
   - "fondinto" → "fond"
   - "verkisto" → "verk"

4. Removed hardcoded `CREATOR_VERBS` and `CREATOR_NOUNS` from ast_aware_retriever.py

**Before (hardcoded):**
```python
CREATOR_VERBS = {'fond', 'kre', 'invent', 'establ', 'inici'}
CREATOR_NOUNS = {'aŭtor', 'kreint', 'fondint', 'inventint', 'iniciatint'}
```

**After (systematic):**
```python
query_agent_nouns = self.semantic_db.get_agent_nouns(query_verb_root)
for syn in self.semantic_db.get_synonyms(query_verb_root):
    query_agent_nouns.update(self.semantic_db.get_agent_nouns(syn))
```

**Why this matters:**
- Works for ANY verb, not just 5 hardcoded "creator" verbs
- Curated additions (like "aŭtoro" for "fond") still work
- Follows Esperanto's regular morphology rules
- No manual updates needed for new verbs
