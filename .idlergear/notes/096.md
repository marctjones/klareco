## Q&A Benchmark Script Fixes (2026-01-06)

Fixed multiple issues in `scripts/benchmark_qa_all.sh` and `scripts/evaluate_qa.py`:

### Bugs Fixed:
1. **Wrong Python script**: Changed from nonexistent `benchmark_qa_enhanced.py` to `evaluate_qa.py`
2. **Wrong benchmark path**: Fixed default path to `data/benchmarks/datasets/qa_benchmark_v1.jsonl`
3. **Wrong Retriever import**: Changed from nonexistent `Retriever` to `HybridFAISSMmapRetriever`
4. **Wrong SlotBasedIndexer init**: Changed from `.load()` method to proper constructor with model paths
5. **Embedding dimension mismatch**: Changed `use_hybrid=True` (128d) to `use_hybrid=False` (64d) to match index
6. **Inhomogeneous array bug**: Fixed `slot_retriever_hybrid.py:298` to properly flatten MOD slots (lists) vs HEAD slots (arrays)

### Current Results (slot_full index):
- Exact Match: 0%
- Partial Match: 12%
- F1 Score: 0.108
- Recall@10: 5.9%
- Avg Latency: 745ms

### Key Insight:
The `slot_full` index was built with 64-dim embeddings (no topical/hybrid mode). The evaluate_qa.py was incorrectly using `use_hybrid=True` which produces 128-dim embeddings, causing FAISS dimension assertion error.
