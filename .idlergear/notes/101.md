## Retrieval Diagnostic Results (2026-01-07)

**CRITICAL BUG FOUND: Embedding Collision in Slot-Based Index**

### Discovery Path
1. User asked to diagnose why Recall@10 is only 5.9% despite corpus having relevant docs
2. Created lightweight diagnostic script to test HNSW self-retrieval
3. Found self-retrieval success only 1/10 (should be 10/10)
4. Discovered 17.5% of first 1000 docs have duplicate embeddings
5. Root cause: Predicate embeddings not captured in copular sentences

### Key Finding
Sentences with structure "X estas Y" (X is Y) all get identical embeddings:
- "La patro estas sana" = same embedding as
- "La patro estas tajloro" = same embedding as
- "La patro estas bona"

Because:
- SUBJ = "patro" (captured)
- VERB = "estas" (captured)
- OBJ = None (predicates go to `aliaj`, not OBJ)
- full_embedding = normalize(SUBJ + VERB) - predicates ignored!
