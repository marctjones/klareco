## AST-First Retrieval Implementation Complete

### What Was Built

1. **`klareco/rag/root_inverted_index.py`** - Core retrieval system
   - `RootInvertedIndex` class for searching
   - `RootIndexBuilder` class for building
   - `FallbackMode` enum: NONE, EMBEDDING, RERANK, FULL
   - `RetrievalStats` for debugging/testing what happened

2. **`scripts/build_root_index.py`** - Index builder script
   - Processes unified_corpus.jsonl (has full ASTs)
   - Outputs root_index.json + documents.jsonl + doc_offsets.npy

3. **`scripts/build_root_index.sh`** - Shell wrapper for long-running build

4. **`tests/test_deterministic_retrieval.py`** - 18 tests for deterministic path
   - All tests pass ✓

### Key Design Decisions

1. **FallbackMode.NONE** - Pure deterministic, logs when fallback would be needed
2. **Stats tracking** - Every search returns stats showing what roots were/weren't found
3. **Synonym expansion via SemanticRelationDB** - Deterministic, not learned
4. **Grammar scoring** - Tense/mood matching boosts scores

### Next Steps

1. Build full index: `./scripts/build_root_index.sh` (runs ~15-30 min)
2. Benchmark deterministic retrieval vs current slot-based
3. Add embedding fallback (when FallbackMode.EMBEDDING)
4. Add reranking (when FallbackMode.RERANK)
