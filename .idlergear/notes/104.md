## Hybrid Synonym Expansion Implemented

Implemented embedding-based synonym expansion for AST-first retrieval (Task #134).

### Changes:
1. **HybridEmbeddings** (`klareco/embeddings/hybrid_embeddings.py`):
   - Added `find_similar_roots()` - searches full vocabulary for similar roots
   - Added `find_similar_roots_fast()` - optimized for retrieval, only searches roots in index

2. **RootInvertedIndex** (`klareco/rag/root_inverted_index.py`):
   - Updated `_expand_roots()` with hybrid approach:
     - Phase 1: SemanticRelationDB (curated synonyms, weight 0.7)
     - Phase 2: Embedding similarity (learned, weight 0.5 * similarity)
   - Embedding expansion only triggers for roots without SemanticDB synonyms
   - Only used when FallbackMode.EMBEDDING or FallbackMode.FULL enabled
   - Added stats tracking: `semantic_db_synonyms` and `embedding_synonyms`

3. **Tests** (`tests/test_deterministic_retrieval.py`):
   - Added `TestHybridSynonymExpansion` class with 3 tests
   - All 21 tests pass

### How It Works:
- Query time: First check SemanticDB for curated synonyms
- If root has no SemanticDB synonyms, use embedding similarity
- Only searches roots that exist in the inverted index (efficient)
- FallbackMode.NONE disables embedding expansion (pure deterministic)
