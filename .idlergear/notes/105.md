## Memory-Efficient Index Implementation Complete

### Changes Made:
1. **RootInvertedIndex** (`klareco/rag/root_inverted_index.py`)
   - Now uses SQLite for disk-backed root lookups
   - ~50MB RAM instead of 8-10GB
   - O(1) root lookups via indexed SQLite queries
   - Automatic conversion from legacy JSON format
   - Caches root set (~10MB) for fast synonym expansion

2. **build_root_index.py** 
   - Outputs directly to SQLite (no JSON intermediate)
   - Removed Phase 3 JSON generation
   - Database is the final index format
   - Still restartable with progress tracking

3. **validate_root_index.py**
   - Works with SQLite format
   - Tests table structure, indexes, metadata
   - Sample root lookups to verify queries work

### File Structure:
```
data/indexes/root_index/
  root_index.db       # SQLite inverted index (~2GB)
  documents.jsonl     # Document texts (mmap access)
  doc_offsets.npy     # Byte offsets for O(1) doc access
```

### Next Steps:
- User needs to rebuild index with `./scripts/build_root_index.sh --fresh`
- Then validate with `./scripts/validate_root_index.sh`
