# Kuzu Graph Implementation for AST-First Retrieval

## Key Insight
Esperanto's fully-annotated ASTs make graph edges **semantic**, not just structural:
- `HAS_ROOT {role: 'subjekto'}` = word is agent/doer
- `HAS_ROOT {role: 'objekto'}` = word is patient/receiver  
- This enables role-aware matching: "hundo mordas" vs "mordas hundon" are different

## Schema
```cypher
CREATE NODE TABLE Root (root STRING PRIMARY KEY, vortspeco STRING)
CREATE NODE TABLE Sentence (id INT PRIMARY KEY, text STRING, subjekto_root STRING, verbo_root STRING, objekto_root STRING)
CREATE REL TABLE IS_SYNONYM (FROM Root TO Root)
CREATE REL TABLE IS_HYPERNYM (FROM Root TO Root)
CREATE REL TABLE HAS_ROOT (FROM Sentence TO Root, role STRING)
CREATE REL TABLE NEXT_SENTENCE (FROM Sentence TO Sentence)
```

## Query Pattern
1. Parse query to AST, extract roles
2. Expand roots via IS_SYNONYM edges
3. Match sentences where roles align
4. Get context via NEXT_SENTENCE for coreference

## Advantage Over SQLite
- Traversals are O(1) not O(n) JOINs
- Pattern matching with variable-length paths (*0..1)
- Natural representation of semantic relationships
