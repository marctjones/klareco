# Kuzu Migration Complete (Phases 1-3)

Successfully migrated from SQLite-based RootInvertedIndex to Kuzu graph database.

## Files Created
- `klareco/rag/kuzu_inverted_index.py` - Kuzu-backed index class (same interface as RootInvertedIndex)
- `scripts/build_kuzu_index.py` - Comprehensive builder for all 3 phases
- `scripts/build_kuzu_index.sh` - Shell wrapper for the builder
- `scripts/validate_kuzu_vs_sqlite.py` - Validation script comparing both backends

## Files Modified
- `klareco/rag/ast_aware_retriever.py` - Added `backend` parameter (IndexBackend.SQLITE or KUZU)
- `klareco/rag/__init__.py` - Exports KuzuInvertedIndex, IndexBackend, KUZU_AVAILABLE

## Kuzu Schema
```cypher
# Nodes
Root(root STRING PRIMARY KEY, doc_freq INT64, total_freq INT64)
Sentence(id INT64 PRIMARY KEY, text STRING, doc_id INT64, sent_idx INT64)
Document(id INT64 PRIMARY KEY, source_name STRING, source_type STRING)

# Edges
HAS_ROOT(FROM Sentence TO Root, role STRING, grammar STRING)
IS_SYNONYM(FROM Root TO Root)
IS_HYPERNYM(FROM Root TO Root)
IS_ANTONYM(FROM Root TO Root)
NEXT_SENTENCE(FROM Sentence TO Sentence)
IN_DOCUMENT(FROM Sentence TO Document)
```

## New Kuzu-Only Features
- `get_synonyms_transitive(root, max_hops=2)` - Transitive synonyms (fond → kre → establ)
- `get_hypernym_chain(root, max_depth=5)` - Hypernym hierarchy (hundo → besto → vivaĵo)
- `get_sentence_context(sent_id, window=2)` - Adjacent sentences via NEXT_SENTENCE
- `search_by_role(verb=, subj=, obj=)` - AST role-aware pattern matching

## Usage
```python
from klareco.rag import ASTAwareRetriever, IndexBackend

# Use Kuzu backend
retriever = ASTAwareRetriever(backend=IndexBackend.KUZU)

# Build index: ./scripts/build_kuzu_index.sh
```
