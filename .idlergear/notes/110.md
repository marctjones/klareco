Kuzu index build completed successfully with CSV bulk loading optimization.

**Performance comparison:**
- Old approach (individual INSERTs): ~7-8 docs/sec = ~7 days estimated
- New approach (CSV bulk loading): ~5,300 docs/sec = 17 minutes actual

**Final index stats:**
- 1.16M roots, 4.38M sentences/documents
- 59.1M HAS_ROOT edges
- 2.1 GB kuzu.db, 1.4 GB documents.jsonl

**Key insight:** Kuzu's COPY FROM CSV is 100-700x faster than individual INSERTs for bulk loading. Always use CSV bulk loading for initial index creation.
