# Retrieval Failure Analysis: Root Cause Found

## The Problem
Query: "Kiam aperis la Fundamento de Esperanto?"
Target doc: "...la Fundamento de Esperanto en 1905..."

Query roots: ['ap', 'fundament', 'esperant']
Target roots: ['fundament', 'fiks', 'lingv', 'esperant', '1905']

The target doc DOES contain 'fundament' and 'esperant', but gets a low score because:
1. Query has 'ap' (aperi = appear), target has 'fiks' (fiksi = establish)
2. These are NOT linked as synonyms in the graph
3. The BM25/scoring penalizes for missing 'ap'

## The Real Issue
The retriever weights ALL query roots equally, including the VERB. But for factual questions like "When did X happen?", the verb is often paraphrased:
- "aperis" (appeared) → "fiksis" (was fixed)
- "kreis" (created) → "fondis" (founded)
- "naskiĝis" (was born) → "venis al la mondo" (came to the world)

## Solutions
1. **Lower verb weight** - Verbs in WHEN/WHERE/WHO questions often get paraphrased
2. **Content root priority** - Weight nouns (Fundamento, Esperanto) higher than verbs
3. **Expand synonym graph** - Add more verb synonyms (ap ↔ fiks, kre ↔ fond, etc.)
4. **Question-aware scoring** - For KIAM questions, prioritize temporal expressions (1905)

## Quick Win
For KIAM (when) questions, the answer MUST contain a date/year. We should:
- Extract temporal expressions from retrieved docs
- Boost docs that contain dates when question type is WHEN
