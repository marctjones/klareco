## AST-Aware Retriever Design - Key Insights (2026-01-10)

### The Core Problem
Pure deterministic retrieval achieves 52% recall@10. Root-bag matching ignores structure - "Esperanto fondis Zamenhofon" would score same as "Zamenhof fondis Esperanton".

### The Ideal Solution
Structure-aware scoring using AST annotations:

1. **Predicate Match (×3.0)**: Verb frame alignment - fond(?, esperant) should match fond(zamenhof, esperant)
2. **Role-Aligned Match (×2.0)**: SUBJ→SUBJ, VERB→VERB, OBJ→OBJ matching
3. **Question Type Satisfaction (×2.0)**: Kiu→entity in subjekto, Kiam→temporal in aliaj
4. **Grammatical Agreement (×1.0)**: tempo, kazo, nombro alignment
5. **Synonym Expansion (×0.5)**: Diminishing weights: 1-hop ×0.7, 2-hop ×0.4

### Synonym/Antonym Handling
- Distance-weighted: direct ×1.0, 1-hop ×0.7, 2-hop ×0.4
- Source priority: ReVo/PIV ×1.0, corpus co-occurrence ×0.6, embeddings ×0.4
- Antonyms: +0.3 normally, +0.8 in negated context

### Key Insight
"The AST annotations are underutilized if we're just doing root-bag matching. The structure IS the semantics in Esperanto."
