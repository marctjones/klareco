## Overview

This directory contains a comprehensive Q&A test set for evaluating the Klareco RAG system. The test set includes 30 questions spanning 13 categories, labeled with expected performance and required capabilities.

**Purpose:**
1. Benchmark current RAG performance
2. Track progress as new capabilities are added (Stage 3/4)
3. Identify which features have highest impact
4. Guide development priorities

## Question Structure

Each question includes:

```json
{
  "id": "factual_001",
  "question": "Kio estas Esperanto?",
  "category": "factual_simple",
  "subcategory": "definition",
  "difficulty": "easy",
  "expected_performance": "works",
  "expected_answer_pattern": "Esperanto estas [definition]",
  "expected_sources": ["fundamento", "wikipedia:Esperanto"],
  "required_capabilities": ["retrieval", "extractive_qa"],
  "notes": "Simple definition question - should work with current pipeline"
}
```

### Fields

- **id**: Unique identifier (category_XXX)
- **question**: The Esperanto question
- **category**: Main category (see below)
- **subcategory**: More specific classification
- **difficulty**: easy | medium | hard | very_hard
- **expected_performance**: works | partial | fails
- **expected_answer_pattern**: What a good answer looks like
- **expected_sources**: Which corpus sources should contain the answer
- **required_capabilities**: What RAG features are needed
- **notes**: Additional context and explanations

## Categories and Required Capabilities

### ✅ Currently Working (8 questions)

**1. factual_simple** (4 questions)
- Simple subject-verb-object questions
- Examples: "Kio estas X?", "Kiu kreis X?", "Kie estas X?"
- Required: retrieval, extractive_qa
- Should work with current structural retrieval

**2. grammar** (3 questions)
- Grammar explanations from Lingvaj Respondoj
- Examples: "Kiam oni uzas 'ge'?", "Kio estas la diferenco inter X kaj Y?"
- Required: retrieval, extractive_qa
- GOLD quality authoritative source

**3. definition** (2 questions)
- Word/concept definitions
- Pattern: "Kion signifas X?", "Kio estas X?"
- Required: definition_extraction, pattern_matching
- Simple extractive QA

### ⚠️ Partially Working (12 questions)

**4. yes_no** (2 questions)
- Yes/no questions requiring stance detection
- Can retrieve evidence but may not classify yes/no
- Required: yes_no_classification, stance_detection

**5. comparison** (2 questions)
- Comparing two concepts
- Can retrieve both but may not contrast them
- Required: comparison_reasoning, contrast_extraction

**6. negation** (2 questions)
- Questions with negation ("NE devas", "NE havas")
- Parser sees 'ne' but semantic handling limited
- Required: negation_understanding, exclusion_logic

**7. enumeration** (2 questions)
- List/enumeration questions
- Can retrieve lists but may not parse structure
- Required: list_extraction, cross_document_aggregation

### ❌ Not Working Yet (10 questions)

**8. pronoun_resolution** (2 questions)
- Questions with pronouns that need resolution
- Examples: "Kion ŝi faris?", "Pri kio Zamenhof parolas en sia respondo?"
- Required: pronoun_resolution, discourse_tracking, coreference
- **Needs**: Stage 3 - Issue #527

**9. multi_hop** (3 questions)
- Questions requiring multi-hop reasoning
- Examples: "Kie loĝis la kreinto de Esperanto?"
- Required: entity_linking, multi_hop_reasoning, answer_fusion
- **Needs**: Reasoning core

**10. semantic_roles** (2 questions)
- Questions about semantic roles (Agent, Patient, Instrument)
- Examples: "Kiu RICEVIS leteron?", "Per kio oni povas...?"
- Required: semantic_role_labeling
- **Needs**: Stage 3 - Issue #525

**11. discourse_relations** (2 questions)
- Questions about discourse structure
- Examples: "Kio estas la kontraŭargumento?", "Kiuj ekzemploj ilustras?"
- Required: discourse_relations, contrast_detection, elaboration
- **Needs**: Stage 3 - Issue #528

**12. temporal_reasoning** (2 questions)
- Questions requiring temporal ordering
- Examples: "Kio okazis ANTAŬ X?", "Kiu respondo estis la plej frua?"
- Required: temporal_ordering, timeline_construction
- **Needs**: Stage 4

**13. causal_reasoning** (2 questions)
- Questions asking "why" (causal explanations)
- Examples: "Kial Zamenhof ne rekomendas X?"
- Required: causal_extraction, explanation_understanding
- **Needs**: Stage 4

## Usage

### Generate Test Set

```bash
# Generate test set (already done)
python scripts/generate_qa_test_set.py \\
    --output data/evaluation/rag_test_set.jsonl
```

### Run Evaluation

```bash
# Evaluate current RAG system (when integrated)
python scripts/evaluate_rag_test_set.py \\
    --test-set data/evaluation/rag_test_set.jsonl \\
    --output data/evaluation/rag_results.jsonl

# Test only questions that should work now
python scripts/evaluate_rag_test_set.py --expected works

# Test specific categories
python scripts/evaluate_rag_test_set.py \\
    --category factual_simple \\
    --category grammar
```

### Inspect Test Set

```bash
# View all questions
cat data/evaluation/rag_test_set.jsonl | jq '.'

# Filter by category
cat data/evaluation/rag_test_set.jsonl | jq 'select(.category == "grammar")'

# Filter by expected performance
cat data/evaluation/rag_test_set.jsonl | jq 'select(.expected_performance == "works")'

# Count by category
cat data/evaluation/rag_test_set.jsonl | jq -r '.category' | sort | uniq -c
```

## Notes

- **Source mapping**: Questions reference corpus sources (e.g., "lingvaj_respondoj:6" = response #6)
- **Answer patterns**: Expected answer patterns help evaluate correctness
- **Capability labels**: Track which Stage 3/4 features unlock which questions
- **Difficulty calibration**: Based on reasoning complexity, not retrieval difficulty
