# Test Set Quality Audit - Additional Files

## Overview

Audited three additional test/training files found in `data/test_sets/`:
- `test_questions_50.jsonl` (50 questions)
- `train_questions_150.jsonl` (150 questions)
- `train_questions_50_fast.jsonl` (50 questions - duplicate of first 50 from train_questions_150)

**Result:** All three files are **GARBAGE** and should be **DELETED**.

---

## Critical Problems

### 1. Grammatically Broken Questions

All questions are generated by a broken auto-generation process that creates incoherent, incomplete sentences:

**Examples from test_questions_50.jsonl:**
```
❌ "Kiu sendis krist prof?"
   (Who sent christ prof? - incomplete words)

❌ "Kiu estas hind lm lm?"
   (Who is hind lm lm? - "lm lm" is gibberish)

❌ "Kion faris si nov influ interpr samtemp?"
   (What did she new influ interpr sametime? - word salad)

❌ "Kion pelis li li mil?"
   (What drove he he mil? - nonsense)
```

**Examples from train_questions_150.jsonl:**
```
❌ "Kiu verkis libr?"
   (Who wrote book? - truncated "libron")

❌ "Kiu konkis ĝi?"
   (Who conquered it? - missing object)

❌ "Kion priskribis financ si idi?"
   (What described financ she idi? - broken)
```

### 2. Wrong/Nonsensical Keywords

The expected keywords don't match the actual answers in the source sentences:

**Example 1:**
- **Source:** "Pro tio, en 1844 Dio sendis profetinon White..."
- **Question:** "Kiu sendis krist prof?"
- **Expected keywords:** `["tio"]` ❌ WRONG
- **Correct answer:** "Dio" or "White"
- **Problem:** Algorithm extracted "tio" (that), which is a conjunction, not the answer!

**Example 2:**
- **Question:** "Kion havas gani?"
- **Expected keywords:** `["kontinent", "klimat"]`
- **Problem:** Vague question with vague keywords

**Example 3:**
- **Question:** "Kion pelis li li mil?"
- **Expected keywords:** `[]` ❌ EMPTY
- **Problem:** No keywords at all!

### 3. Source Material NOT in Corpus

**CRITICAL:** The source sentences used to generate these questions **are not in the corpus**!

**Test 1:**
```bash
Source: "Pro tio, en 1844 Dio sendis profetinon White..."
grep -c "profetinon White" data/corpus/unified_corpus.jsonl
→ 0 (NOT FOUND)
```

**Test 2:**
```bash
Source: "La talibanoj inter multaj aliaj decidis ŝanĝis la flagon..."
grep -c "talibanoj" data/corpus/unified_corpus.jsonl
→ 0 (NOT FOUND)
```

**Implication:** Even if the questions were grammatical, the system could never answer them because the source material isn't in the corpus!

## Root Cause Analysis

The auto-generation algorithm has these bugs:

1. **Word Truncation:** Cuts words mid-stem ("kristanan" → "krist", "profetinon" → "prof")
2. **Keyword Extraction:** Extracts wrong words (conjunctions, articles instead of content)
3. **Grammar Generation:** Produces incomplete/malformed questions
4. **No Corpus Validation:** Generates questions from sources not in the target corpus

**Lesson:** Auto-generated test sets require:
- Human review for quality control
- Corpus validation (ensure answers exist)
- Grammar checking
- Keyword verification

---

## Conclusion

All three files are **completely unusable** for:
- ❌ Evaluation (broken questions, wrong keywords)
- ❌ Training (would teach incorrect patterns)
- ❌ Testing (source material not in corpus)

**Action:** Delete all three files immediately to avoid accidental use.
