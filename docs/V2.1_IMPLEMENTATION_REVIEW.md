**Date**: 2026-03-23
**Branch**: v2.0-ast-native
**Key Reference**: `docs/COMPREHENSIVE_AI_SYSTEM_DESIGN.md`

## Executive Summary

The v2.1 redesign aims for a **95%+ deterministic system** using Pure Esperanto semantic ontology. Current status:

- ✅ **Parser**: 100% complete (16 grammar rules, deterministic)
- ✅ **Fact Extraction**: Complete (`klareco/rag/fact_extractor.py`)
- ✅ **Root Embeddings**: Trained (320K params, needs retrain with clean vocab)
- ✅ **Extractive QA**: Complete with reranking and M1 filtering
- ⚠️ **Semantic Annotations**: NOT started (requires 200-1000 roots manually annotated)
- ⚠️ **Schema Classification**: NOT started (deterministic pattern matching)
- ⚠️ **RST Relations**: NOT started (discourse marker patterns)
- ⚠️ **Pure Esperanto Ontology**: NOT started (4-layer taxonomy)

**Critical Gap**: The semantic annotation layer is not implemented. The redesign depends on manually annotating roots with semantic classes, which is a prerequisite for deterministic schema classification.

## What We Don't Have ❌

### 1. Pure Esperanto Semantic Ontology (Critical Gap)
**Reference**: COMPREHENSIVE_AI_SYSTEM_DESIGN.md Part 2.1
**Status**: NOT started
**Priority**: **HIGHEST** - Entire v2.1 redesign depends on this

**Required**:
1. **Layer 1: Leksika Semantiko** (Lexical Semantics)
   - Verbaj Klasoj: 50-100 verb classes (kreado, movo, pensado, etc.)
   - Aspektaj Klasoj: 4 aspectual classes (stato, aktiveco, plenumigo, atingaĵo)
   - Substantivaj Klasoj: 80-120 noun classes (persono, animalo, loko, etc.)

2. **Layer 2: Kadra Semantiko** (Frame Semantics)
   - Semantikaj Kadroj: Semantic frames with core/peripheral roles
   - Temaj Roloj: Thematic roles (Aganto, Paciento, Temo, etc.)

3. **Layer 3: Diskursa Semantiko** (Discourse Semantics)
   - RST Rilatoj: 25-30 discourse relations (rezulto, kaŭzo, kontrasto, etc.)
   - Discourse markers mapped to relations

4. **Layer 4: Skema Semantiko** (Schema Semantics)
   - Three schema types: Biografia, Difina, Okazaĵa
   - Schema slots with importance weights

**Deliverable**: `esperanto_terminology.json` with complete Pure Esperanto taxonomy

**Effort**: 1-2 weeks for design, then ongoing annotation

    for slot_name, slot_def in BIOGRAPHICAL_SCHEMA.items():

## Critical Path Analysis

To implement v2.1 redesign, we MUST do these in order:

1. **Design Pure Esperanto Ontology** (1-2 weeks)
   - Cannot proceed without this
   - Defines all semantic classes and schema slots

2. **Annotate 50 Roots for Validation** (1 week)
   - Proves the approach works
   - Enables Phase 0 testing

3. **Implement Schema Classification** (1 week)
   - Core deterministic component
   - Depends on (1) and (2)

4. **Extend Kuzu Schema** (1 week)
   - Database support for semantic annotations
   - Can be done in parallel with (3)

5. **Validate on 10 Questions** (3 days)
   - GO/NO-GO decision point
   - If successful → continue
   - If not → reassess

**Minimum to Start**: Tasks 1-2 (Design ontology + annotate 50 roots) = 2-3 weeks
